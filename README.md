# Android from First Principles

Four books, published at https://akbarbs.github.io/android/

| Edition | Path |
|---|---|
| The Kotlin language | `kotlin-language/` |
| Kotlin and Jetpack Compose | `kotlin/` |
| Java and the View system | `java/` |
| React Native with TypeScript and Expo | `react-native/` |

Each book is one self-contained HTML file. Code samples in the three Android books are illustrative and have not been compiled. The samples in the Kotlin language book were compiled and run with kotlinc 2.4.20, except three Android-only blocks.
